# Creation flow follow-up

Post creation now supports Save for Later and a `/postdrafts` list. Drafts keep their title, body, and originating community in browser storage. Saving a resumed draft updates the existing record. Back and Post drafts also save unfinished post content before leaving; a storage failure keeps the editor open.

Create/Save for Later remain grouped together while Discard sits at the far right. Both post and event Discard actions always open a confirmation overlay, including on empty forms. Cancelling or pressing Escape keeps the editor intact. Confirming discard removes the current saved draft when one exists.

Community creation uses the same centered card, typography, genre chips, field hints, and action styling. Its Back action confirms before abandoning edits. Community publication retains the app's existing prototype navigation; no backend was introduced.

Back controls cover community details, post details, post/community creation, post drafts, search, chat, profile, login/sign-up, and event dialogs. Home, Explore Music, Communities, Events, and My Collections remain top-level entry points.
